In this project, the deep learning time series forecasting model N-BEATS (Neural Basis Expansion Analysis Time Series) was applied to past market data to predict future Relative Strength Index (RSI) values of a stock. This produced rolling forecasts, inputting 30 days of data to predict the following seven. This was then compared to the actual RSI values obtained through the yFinance python library. The rolling forecasts had average values calculated which were displayed in a smoothed graph.
